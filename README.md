# NovaFit — Fitness & Wellness Studio 🏋️‍♂️🧘‍♀️

A premium, fully responsive landing page built to demonstrate foundational frontend development skills, including semantic HTML structure, CSS Grid, Flexbox, and modern UI design principles.

## 🚀 Live Demo
[View the Live Project Here](https://novafit-seven.vercel.app/)

## 🎯 Project Objective
This project was developed as part of the Level 1 Foundation module (Days 1-10) for a Frontend Developer Internship. The goal was to build a complete, responsive landing page from scratch without relying on any CSS frameworks like Bootstrap or Tailwind.

## ✨ Features
*   **Modern & Premium UI:** Designed with a clean, high-end aesthetic.
*   **Fully Responsive:** Fluid layout that perfectly adapts to mobile, tablet, and desktop screens using media queries.
*   **Advanced CSS Layouts:** Built utilizing CSS Grid for the service/pricing cards and Flexbox for navigation and center alignments.
*   **Smooth Navigation:** Implemented pure CSS scroll behavior for seamless section-to-section transitions.

## 🛠️ Technologies Used
*   **HTML5:** Semantic markup (`<header>`, `<section>`, `<main>`, `<footer>`) for better accessibility and SEO.
*   **CSS3:** Custom CSS variables, pseudo-elements, and smooth hover transitions.
*   **Layout Systems:** CSS Grid & Flexbox.
*   **Deployment:** Hosted live using Vercel.
